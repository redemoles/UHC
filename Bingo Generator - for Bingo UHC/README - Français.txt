# Générer et installer des grilles de bingos pour Bingo UHC

1. Lance le programme bingo_generator 
2. Envoie le .zip généré dans [nom_de_map]\datapacks\
3. Sur Minecraft, actualise avec /reload

# Modifier la liste des items disponibles pour le générateur de bingos

Solution simple
1. Dans items_all, supprime la liste des items indésirables

Solution avancée
1. Ouvre le programme advancements_generator
2. Efface le # devant une liste d'item que tu souhaites retirer (exemple : #cherry)
   Ajoute un # devant une liste d'item que tu souhaites ajouter (exemple : silk_touch_block)
3. Supprime le dossier items_all et lance le programme advancements_generator
