# Generate and install bingo boards for Bingo UHC

1. Run the bingo_generator program 
2. Place the generated .zip file in [map_name]\datapacks\
3. In Minecraft, reload the game with /reload

# Modify the list of items available to the bingo generator

Simple solution
1. In items_all, remove the list of unwanted items

Advanced solution
1. Open the advancements_generator program
2. Remove the # in front of any item list you want to remove (example: #cherry)
   Add a # in front of any item list you want to add (example: silk_touch_block)
3. Delete the items_all folder and run the advancements_generator program
